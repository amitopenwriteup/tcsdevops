## 📝 Contents

* **Linux** → Day 1 to Day 3 notes (basic commands, scripting, environment setup).
* **Jenkins** → Day 2–3 (CI/CD, pipelines, jobs, integration).
* **Docker** → Day 4–5 (images, containers, networking, volumes).
* **Kubernetes (K8s)** → Day 6–10 (pods, deployments, services, configs).
* **Labs** → Hands-on exercises & lab notes.
* **PDFs** → Guides for AWS CodeBuild and CKA VM setup.

## 🚀 Usage

1. Browse the `Day X` files to follow along topic-wise.
2. Use `labnotes/` and `labnotesbatch8.txt` for practice labs.
3. Refer to `AWS Code Build.pdf` and `CKA VM setup.pdf` for cloud and Kubernetes setup.
